# NBA Management System 🏀

A comprehensive software solution for managing NBA teams, players, managers, games, sponsors, seasons, and finances. Built with object-oriented principles and service-oriented architecture, this system provides data management capabilities for basketball organizations.
---

## 🌟 Features

### **Team Management**
- Create, update, and delete teams.
- Retrieve teams by name, ID, or conference.
- Track team performance metrics.
- Manage team rosters and staff.

### **Player Management**
- Add, update, and remove NBA players.
- Sort and filter players by various criteria:
  - Age
  - Salary
  - Position
  - Performance stats

### **Manager Management**
- Comprehensive management of team personnel.
- Advanced search functionality:
  - Search by name
  - Search by ID
  - Filter by experience

### **Game Management**
- Schedule and manage game events.
- Features include:
  - Game scheduling
  - Score tracking
  - Date-based sorting
  - Team-specific game retrieval

### **Season Management**
- Full season lifecycle management.
- Search capabilities:
  - By season name
  - By year
  - By season ID
- Track season statistics and records.

### **Sponsor Management**
- Efficient sponsor relationship management.
- Advanced filtering options:
  - By age range
  - By company name
- Track sponsorship agreements and terms.

### **Fund Management**
- Comprehensive financial tracking.
- Features include:
  - Team budget management
  - Sponsorship revenue tracking
  - Expense monitoring
  - Financial reporting
